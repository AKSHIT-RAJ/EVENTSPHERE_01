CONNECTING FRONTEND & BACKEND
═════════════════════════════════════════════════════════════════════════════════

After deploying both:

1. Get your backend URL from deployment service
   Example: https://eventsphere-prod-up.railway.app

2. In Vercel Dashboard:
   • Go to Settings → Environment Variables
   • Add new variable:
     Name: VITE_API_URL
     Value: https://your-backend-url/api
   • Save and redeploy

3. Frontend automatically uses this URL in production!

LOCAL TESTING (WITH DOCKER)
═════════════════════════════════════════════════════════════════════════════════

To test everything locally with Docker:

1. Make sure Docker is installed
2. Run: docker-compose up
3. Frontend: http://localhost:3000
4. Backend: http://localhost:8080
5. Both services run together with correct networking

Without Docker:

Terminal 1 - Backend:
  cd backend
  mvn spring-boot:run
  (runs on http://localhost:8080)

Terminal 2 - Frontend:
  cd frontend
  npm install
  npm run dev
  (runs on http://localhost:5173)
